# AdventureWorks → Snowflake Migration Showcase

Static website documenting the end-to-end migration of AdventureWorks DW (SQL Server + SSIS + Power BI) into Snowflake using Factory AI.

## Deploy to Vercel

```bash
npx vercel --prod
```

Or connect the `website/` directory to Vercel via Git integration.

## Local Preview

```bash
cd website
python3 -m http.server 8080
# Open http://localhost:8080
```
